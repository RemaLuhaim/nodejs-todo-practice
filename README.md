# Node.js To-Do Task Practice

This is a simple practice project built while learning Node.js backend development.

## Technologies Used
- Node.js
- Express.js
- EJS
- MongoDB
- Nodemon

## Features
- Create new tasks
- View tasks
- Manage tasks using a simple backend structure

## Purpose
This project was built as part of backend development practice to understand routing, MVC structure, and server-side rendering using EJS.
